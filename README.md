# AOT2 Attack On Titan: Final Battle Modding Toolkit

The purpose of this toolkit is to allow its users to extract game LINKDATA.BIN files.

It consists of:

- [AOT2-LINKDATA-EXTRACTOR](https://github.com/the-real-thunderlol/AOT2-LINKDATA-EXTRACTOR): To extract the LINKDATA file.
- [AOT2-G1T-EXTRACTOR](https://github.com/the-real-thunderlol/AOT2-G1T-EXTRACTOR): To Extract G1T files.
- [AOT2-ZLIB-DECOMPRESSOR](https://github.com/the-real-thunderlol/AOT2-ZLIB-DECOMPRESSOR): To decompress Compressed archives.

Currently it can only extract, decompress, and convert G1T files into DDS (Texture) files.

- This implementation allows you to do all 3 in a **single batch** with the help of `recursive_extractor.py`
